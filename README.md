### Проект Foodgram

## Описание проекта
Foodgram - это проект для размещения рецептов.

Пользователю необходимо зарегистрироваться и затем авторизироваться, чтобы у была возможность оставлять собственные рецепты на сайте, а также добавлять понравившиеся рецепты в список покупок, избранное и подписываться на других пользователей. Неавторизированным пользователям будет доступен только просмотр рецептов и возможность получения ссылки на рецепт.

Ингредиенты и теги для рецептов моет добавлять только администратор.

**В проекте доступно**:
для всех пользователей:
    - просмотр рецептов
    - просмотр страниц пользователя
    - создание аккаунта
    - фильтрация рецептов по тегам
для авторизированных пользователей:
    - вход в систему под своим логином (email) и паролем и выход из нее
    - создание, редактирование и удаление собственных рецептов
    - добавлять и удалять рецепты в список покупок, получать список с необходимыми ингредиентами для рецептов, просмотр страницы со списком покупок
    - добавлять и удалять рецепты в избранное, просмотр страницы избранноого
    - подписываться и отписываться на других пользователей, просмотр страницы своих подписок
для администратора доступно всё, что указано выше и ещё:
    - изменение пароля любого пользователя
    - создание, блокировка и удаление аккаунтов пользователей 
    - редактирование и удаление любых рецептов
    - добавление, удаление и редактирование ингредиентов
    - добавление, удаление и редактирование тегов



## Пользовательские роли
**Аноним** — доступен просмотр рецептов (включая фильтрацию по тегам).
**Аутентифицированный пользователь (user)** — доступно создание рецептов, а также удаление и редактирование.
**Администратор (admin)** — доступны права администратора, также доступно создание рецептов, тегов и ингредиентов (и их добавление в рецепты). 



## Используемые технологии
*Проект реализован с использованием следующего функционала*: 
- Python 3.12
- Django 5.1.1 
- Django REST Framework 3.15.2

Для аутентификации в Foodgram используются Token Authentication.  
Все необходимые для работы Foodgram зависимости перечислены в requirements.txt
Рекомендуется перед установкой развернуть виртуальное окружение с верисей python 3.12:

Bash:
```
py -3.12 -m venv venv 
```

Для установки зависимостей необходимо выполнить установку зависимостей:
```
pip install -r requirements.txt
```


## Описание API
API предоставляет следующие возможности:

**Пользователи**
- Получение списка всех пользователей
- Регистрация пользователей
- Получение пользователя по id
- Получение данных своей учетной записи
- Добавление/удаление фото профиля (avatar)
- Изменение пароля
- Получение/удаление токена

**Рецепты**
- Получение списка рецептов
- Получение информации о рецепте по id
- Добавление, обновление и удаление рецептов

**Теги**
- Получение списка тегов

**Ингредиенты**
- Получение списка ингредиентов


**Список покупок**
- Скачать список покупок
- Добавление и удаление рецепта из списка покупок

**Избранное**
- Добавление и удаление рецепта из избранного

**Подписки**
- Возможность подписаться и отписаться от пользователя

Для вывода результатов запросов включена пагинация (вывод результаов разбит постранично), результаты выводятся по 6 элементов на один запрос.  
Для перемещения по страницам необходимо использовать переменную /?page=x при запросе на эндпоинт.
Возможна фильтрация вывода списка рецептов по списку покупок (?is_in_shopping_cart), избранному (?is_favorited), тегам (?tags) - можно одновременно несколько тегов, автору (?author), ограничить число выводимых рецептов (?limit)

Пример
```
GET /api/recipes/?is_in_shopping_cart=1
GET /api/recipes/?limit=3
GET /api/recipes/?tags=dinner&?tags=lunch

```

### Как запустить проект:

Клонировать репозиторий и перейти в него в командной строке:

```
git clone https://github.com/Andrey-Dubov-25/foodgram
```

```
cd foodgram
```
```

Cоздать и активировать виртуальное окружение:

```
python3 -m venv venv
```

```
source venv/Scripts/activate
```

```
python3 -m pip install --upgrade pip
```

Установить зависимости из файла requirements.txt:

```
pip install -r requirements.txt
```

Выполнить миграции:

```
python3 manage.py migrate
```

Запустить проект:

```
python3 manage.py runserver
```
